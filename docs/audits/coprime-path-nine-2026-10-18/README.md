# Nine-edge-path structural certificate audit

These positive certificates support the
[conditional structural theorem](../../coprime-path-nine-2026-10-18.md)
for G_17. They do **not** prove P_cop(9)=17 or provide an avoiding coloring.
The existing exact k=7,8 certificates and release archive are unchanged.

## Reproduce the independent checks

From the repository root, no installation or SAT solver is needed:

```sh
python3 -I -S -O src/coprime_path_structure_certificates.py cuts \
  docs/audits/coprime-path-nine-2026-10-18/cuts.json.gz
python3 -I -S -O src/coprime_path_structure_certificates.py faults \
  docs/audits/coprime-path-nine-2026-10-18/fault-families.json.gz
python3 -I -S -O src/coprime_path_structure_certificates.py extensions \
  docs/audits/coprime-path-nine-2026-10-18/extensions.json.gz
```

Expected results are 62,322 cuts; 262 deletion orbits covering 2,380 deletions
with 30,671 paths; and 63,859 extension cases on 1,253 qualifying cuts.
The checker derives case coverage from the input's integer task parameters,
rejects missing or duplicate cases, and validates all path edges. The
archived tasks have `n=17` and `target_edges=9`; changing these parameters
changes the assertion being checked. Integration tests pin both parameters
and the case counts. The `cuts` mode checks every smaller side from
`minimum_side` to floor(n/2); for even n, both equal-half orientations are
required. `-O` does not disable any validation.

The resilience certificate supplies vertex classes and a path family for
each deletion signature. Every class transposition must preserve gcd
adjacency. Exhaustive edge-transversal checking establishes that at most
four edge faults cannot hit every path in a family. No unproved coloring
symmetry, search status, or external solver result is trusted.

## Files and provenance

| File | Purpose |
| --- | --- |
| `cuts.json.gz` | One crossing path for each required cut |
| `fault-families.json.gz` | Path families resisting four edge faults |
| `extensions.json.gz` | One path for each qualifying cut and distinguished edge |
| `independent-checks.json` | Results of the three isolated optimized checks |
| `searches.json` | Bounded SAT diagnostics, explicitly inconclusive overall |
| `tests.txt`, `coverage.json` | Checker tests and measured statement coverage |
| `focused-tests.txt` | The 494-test focused regression result |
| `manifest.json` | SHA-256 hashes of evidence and validation sources |

Paths were generated by bounded DFS and, for resilience, a path-family /
hitting-set loop. A 60-second partial resilience run was completed using
verified deletion orbits. A 30-second partial extension run was completed
by requiring the distinguished edge at an endpoint. All final cases are
checked independently; those partial runs were not treated as proofs.
Generation timings in the JSON files are diagnostic metadata. The cut file
adds the explicit `minimum_side=5` parameter to the original generated data.

The new tests include direct enumeration of every set family on a three-edge
universe, genuine small certificates with true and false twins, malformed
evidence, isolated optimized CLI runs, and all three archived certificates:

```sh
python -m pytest -q tests/test_coprime_path_structure_certificates.py \
  --cov=coprime_path_structure_certificates --cov-report=term-missing
```

All 55 new tests and 494 focused regressions passed locally. Statement
coverage of the checker logic is 100%; the repository's existing coverage
configuration excludes `main` bodies. CLI behavior is exercised separately
by subprocess integration tests.

The mathematical deduction additionally uses the two published theorems
cited in the research note. This is independently checked finite computation
plus a written argument, not a Lean formalization or a novelty assessment.
